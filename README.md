## 🚀 Sobre JIVOTECK

**JIVOTECK** es una startup de base tecnológica fundada en **Aguascalientes, México**, con enfoque y alcance global. Fusionamos la ingeniería de control y automatización física con el desarrollo de software moderno, la orientación técnica estratégica y el marketing especializado para empresas del sector tecnológico e industrial.

### Nuestros 4 Pilares de Especialización:

1. **Automatización**:
   - Programación de PLCs y sistemas SCADA.
   - Integración de sensórica avanzada, robótica y protocolos industriales (Modbus, Profinet, EtherNet/IP).
   - Simulación y gemelos digitales de líneas de manufactura.
2. **Programación**:
   - Desarrollo de aplicaciones web y software a la medida de alto rendimiento.
   - Arquitecturas escalables en la nube, APIs RESTful y microservicios.
   - Dashboards operativos y telemetría en tiempo real.
3. **Orientación & Consultoría**:
   - Diagnóstico profundo de infraestructura técnica y hojas de ruta de digitalización.
   - Selección óptima de componentes, software y proveedores.
   - Acompañamiento y dirección técnica estratégica.
4. **Marketing Tecnológico**:
   - Estrategia de comunicación y posicionamiento B2B con lenguaje de ingeniería.
   - Posicionamiento SEO de alta especialidad y generación de demanda.
   - Lanzamientos y narrativa de producto tech.

## ⚡ Proyecto Destacado: Industrialpedia (Próximamente)

**Industrialpedia** es un proyecto concebido, desarrollado y respaldado al 100% por **JIVOTECK**.  
Consiste en la plataforma inteligente de homologación, comparativa técnica y sustitución cruzada de componentes industriales multi-marca (FESTO, SMC y fabricantes líderes mundiales), reduciendo tiempos muertos y optimizando el inventario de refacciones.

## 💻 Desarrollo Local

Para ejecutar el frontend en tu entorno local:

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo en tiempo real
npm run dev

# Compilar para producción
npm run build

# Vista previa de la compilación de producción
npm run preview
```

## 🌐 Despliegue Automatizado

El repositorio cuenta con un flujo configurado en `.github/workflows/deploy.yml` para desplegar automáticamente el frontend a **GitHub Pages** en cada actualización de la rama `main`.
